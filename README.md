# NEUROEDGE

## 1. What is NeuroEdge?

NeuroEdge is an FPGA-based Spiking Neural Network (SNN) accelerator for **Partial Discharge (PD) detection and classification** in power systems. It listens to short acoustic waveforms and decides, in a few microseconds, whether a PD is happening and which type it is.

There are 3 common types of partial discharge in high-voltage systems, plus a no-PD class:

| Class | Description |
| :--- | :--- |
| PD in Air | Discharge across an air gap |
| PD in Void | Discharge inside an air cavity in solid insulation |
| Corona | Discharge around a sharp conductor tip |
| No PD | Background noise (high voltage on, no discharge) |

Why SNN + FPGA? An SNN only does work when a spike arrives (*event-driven*), and it needs only additions, no multiplications. This makes it power efficient on an FPGA and very low latency, which suits an edge monitoring device.

## 3. Dataset & Model

- **Dataset:** [Zenodo 20049048](https://zenodo.org/records/20049048), *Acoustic waveforms generated by several types of partial discharges in laboratory environment*. It contains 4 classes × 1000 waveforms and each waveform has 125 samples at 500 kS/s (a 250 µs window)
<img width="600" height="330" alt="image" src="https://github.com/user-attachments/assets/726f4ed8-4190-45c9-8938-7fa49351fdd0" />     

- **Split:** block split per class: train 70%, validation 15%, test 15% (600 test windows)
- **Normalization:** each window is divided by its own peak. The raw amplitude differs a lot between classes (Air is thousands of times louder than noise), so this forces the model to learn the waveform *shape* instead of loudness
- **Spike encoding (delta / level-crossing):** for every sample, the delta, Δx = x[t] − x[t−1] is compared against 4 thresholds (thresholds come from quantiles of |Δx| on the training data). Channels 0–3 fire when the signal rises past θ1..θ4, and channels 4–7 fire when it falls past them    
- **Model:** SNN `8 → 128 LIF → 4 LIF`, no bias, β = 0.875, trained with surrogate gradients (snnTorch) and int8 quantization-aware training. The prediction is the output neuron with the most spikes

## 4. Hardware Design

- **Target:** AMD Kria KV260 (Zynq UltraScale+), PL clock 100 MHz.   
- **`lif_neuron.v`:** an integer LIF neuron. Leak is done with a shift (`mem − (mem >>> 3)`), the membrane is 16-bit with saturation, and reset is by subtraction.   
- **`snn_core.v`:** 128 hidden + 4 output neurons running in parallel, int8 weights stored in logic, spike counters and argmax. It needs about 3 clock cycles per timestep.
- **`snn_axi_wrapper.v` / `snn_axi_lite.v`:** AXI4-Lite registers (start, done, class, spike counts, latency counter) and a window buffer, so the ARM CPU can send a window and read the result.
- **Golden model:** an integer-only Python model that computes exactly what the hardware computes. It is the reference for checking the RTL bit by bit.

## 5. Software Design

### 5.1 Training Architecture

```
waveform → normalize → delta encode → SNN (snnTorch, QAT int8) → int8 weights + params.json
                                                                → golden model → test vectors
```

- Notebook `neuroedge_snn.ipynb` runs everything: data exploration, splitting, encoding, training, and export.
- The exports (`w1_int8.mem`, `w2_int8.mem`, `params.json`, `test_vectors.npz`) feed the RTL simulation and the board scripts.
the training results are shown in notebook.   


### 5.2 Board Software

Python scripts on the KV260 load the bitstream, send test windows over AXI, and collect accuracy, latency and power (`bench_fpga.py`). A CPU-only version (`bench_cpu.py`) serves as the baseline, and `compare.py` merges both into one table.

## 6. How to Use

**1. Train and export (PC)**
```bash
pip install numpy pandas matplotlib scikit-learn torch snntorch
```
And then run all cells in this project's Jupyter Notebook for training

**2. Run the inference on Ubuntu for 600 window**
- connect the JTAG wire and Ethernet from FPGA to local computer
- open the FPGA Ethernet IP and serial COM port using MobaXterm
- run server to receive serial data with
```
sudo TTY=ttyPS1 bash start_uart_server.sh fpga --base 0xA0000000 --fclk 100e6
```
- run serial publisher from local computer using
```
python send_spikes_uart.py --com=COM16 --verbose
```
then serial receiver (server) will start listening to the serial publisher. for the inference (testing) only uses 600 window data. After each of the measurement, the LED lights will turn on based on the class classification.
